# 🏏 IPL 2025 Batters - Data Analysis & Visualization

> A comprehensive data-driven analysis of top batters performance in IPL 2025 using Python.
> **Internship Task 1 @ Arithmatrix Technology**

### 📖 Overview
This project analyzes the performance of top batters in IPL 2025 using Python for data visualization and insight generation. The analysis focuses on consistency, strike rate, and team-wise contributions.

### 📂 Dataset
- **Source:** IPL 2025 Official Stats
- **File:** IPL2025 Batters.csv
- **Features:** Player Name, Team, Matches, Runs, Average, Strike Rate, 100s, 50s

### 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
- Git & GitHub

### 📊 Visualizations
1. Top 10 Run Scorers - Bar Chart
2. Team-wise Runs Distribution - Pie Chart
3. Average vs Strike Rate - Scatter Plot
4. Most Centuries & Half-centuries - Bar Chart

### 🔍 Key Insights
- Virat Kohli was the highest run scorer in IPL 2025
- RCB had the most consistent batters
- Strike rate above 150 indicates aggressive batting style
- Emerging players outperformed expectations in 2025
